# BOOKING-LAYOUT-CHANGES — раскладка карточки брони, шрифт цифр, центрирование

Перенесён подход из согласованного референса. **Логика брони не тронута**
(расчёт цены, выбор стола/мест, верификация, отправка, payload — без изменений):
правки только в раскладке страницы, классах и стилях. `npm run build` зелёный.

## Что изменилось

### Задача 1 — Раскладка без сжатия
- Страницы брони (`/restaurants/[slug]/reserve`, `/r/[slug]/book`): громоздкий
  левый блок-колонка с названием заменён на **компактную верхнюю строку**
  `.reserve-topbar` (пилюля «← К ресторану» + надзаголовок + название ресторана).
- `.public-reserve-page` теперь **одноколоночная** (верхняя строка → форма во всю
  ширину) вместо `[сайдбар-название | форма 760px]`. Освободившаяся ширина ушла
  форме.
- **Схема зала получает полную ширину колонки формы** (≈760px на 1440 вместо
  ≈430px). Доска выше (`min-height:460px`), а столы крупнее автоматически —
  виджет масштабирует зал под ширину доски. Сводка-сайдбар «Ваша бронь» чуть
  шире (340px) и остаётся липкой.
- ≤1180px — одна колонка, сводка — фикс-панель снизу с `env(safe-area-inset-bottom)`
  (как и было в редизайне формы).

### Задача 2 — Шрифт цифр на схеме
- Номера столов (`.booking-table-core strong`, `span`, `small`) и номера мест
  (`.seat-dot`) переведены на `var(--font-sans)` (вес 800 у номера стола). Serif
  (Playfair) на схеме больше не используется. Крупные заголовки секций — serif.

### Задача 3 — Центрирование
- `.seat-dot` → `display:grid; place-items:center` (номер строго по центру
  кружка; размещение кружков вокруг стола — прежняя формула виджета по окружности).
- `.booking-table-core` → `display:flex; flex-direction:column; align-items/
  justify-content:center` (номер/места/статус по центру). Убраны ручные сдвиги.

### Задачи 4–5
- Степпер, тёплая палитра столов (свободен=белый, выбран=`--accent`,
  занят=приглушённый, депозит=`--warning`), пульс свободных, сводка с
  disabled-причиной — уже были внедрены ранее, сохранены. Выбор длительности
  (время начала + окончания) сохранён, не схлопнут.

## Как проверить
На **1440 / 1024 / 768 / 390** открыть `/restaurants/<slug>/reserve`:
- Схема зала занимает основную ширину, столы крупные, ничего не зажато; сводка
  справа залипает (≤1180 — снизу).
- На схеме нет serif-цифр; номера столов и мест читаются как sans, по центру.
- Выбор стола/мест, расчёт цены (депозит), верификация и отправка работают как
  раньше.

## Откат
Ветка `booking-layout`. Откат — `git revert` коммита; правки чисто
презентационные.
