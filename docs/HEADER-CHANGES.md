# HEADER-CHANGES — хедер V2 (поиск + текстовые категории)

Компактный хедер из одной зоны + категории тихими текст-ссылками. Бренд и
палитра не менялись. `npm run build` + `tsc` зелёные.

## Что изменилось

### Строка 1 — хедер
- **`AppHeader` (public):** теперь `логотип · поиск (flex:1) · «Мои брони»`.
  «Мои брони» — заполненная акцентная кнопка (`.button.compact`).
- **Новый `HeaderSearch`** (`components/layout/HeaderSearch.tsx`, client): поле
  с лупой, submit → `/restaurants?q=…#restaurant-list` (каталог уже фильтрует по
  `q`, общий стейт не нужен). Десктоп — поле всегда раскрыто; **мобильный** —
  лупа-иконка, по тапу разворачивается в верхнюю строку поиска (Esc/крестик —
  закрыть), с `env(safe-area-inset-*)`.

### Строка 2 — категории
- `ChipSlider` (пилюли + кнопки-стрелки) → плоский `<nav class="catalog-categories">`
  из **текст-ссылок**: активная — `--ink` + `font-weight:700` + нижнее
  подчёркивание `2px --accent`; остальные — `--muted`, без фона/рамки. Нативный
  горизонтальный скролл + `scroll-snap`, **без стрелок**, лёгкое затухание справа
  (sticky-псевдоэлемент). Ссылки ведут в те же фильтры (`filter.href`) — фильтрация
  каталога не изменилась.

### Адаптив
- ≤720px: брендовое слово не растёт (`flex:0 1 auto`), чтобы лупа + «Мои брони»
  помещались; поиск — иконка с разворотом. Категории скроллятся.
- Поправлено: `.public-header .header-actions` пряталась на ≤640px
  (`display:none` — раньше это был пустой декоративный блок); теперь там кнопка
  «Мои брони», поэтому блок снова показывается.

### Чистка
- `ChipSlider.tsx` не используется → перемещён в `archive/`.
- Удалён основной мёртвый CSS пилюль/стрелок (`.chip-slider-*`,
  `.catalog-quick-row`). Несколько мелких dead-оверрайдов `.chip-slider-*` /
  `.quick-filter-row` оставлены (безвредны; полный CSS-свип отложен, как и
  ранее — каскад globals.css завязан на порядок).

## Как проверить
На **1440 / 768 / 390**, страница `/restaurants`:
- Хедер: лого · поиск · «Мои брони» в одну строку, sticky. Ввод в поиск + Enter →
  каталог фильтруется по `q`. Мобильный: лупа разворачивается, «Мои брони» видна.
- Категории: текст-ссылки, активная подчёркнута акцентом, без пилюль/стрелок,
  скролл с затуханием; клик ведёт в тот же фильтр.
- Тач-цели ≥44px (поиск/кнопки/иконки), фокус-кольца на поле.

Ветка `header-v2`. Презентационные правки + 1 client-компонент; откат — `git revert`.
