# CHANGES — design polish (branch `design-polish`)

Точечная дизайн-полировка поверх существующей вёрстки. Палитра, бренд и
структура страниц не менялись. Каждая задача — отдельный коммит. Сборка
`npm run build` проходит.

## Что сделано

### Task 1 — Аудит → [STYLE-MAP.md](STYLE-MAP.md)
Карта каскада `globals.css` (~24 слоя, «последний побеждает»), где лежат
стили каждого блока, и две системы фильтров (актуальная `catalog-filter-*`
vs легаси `restaurant-filter-bar`). _Коммит:_ `Task 1`.

### Task 2 — Фильтр-бар каталога
Сетка с фиксированными колонками → `flex-wrap` (≥681px, добавлено последним
в каскад). Поле поиска `flex:1 1 240px`, чипы — по ширине контента.
- **Было:** подписи обрезались («ип заведени», «Средний чен»), а на
  681–1179px фильтры «Средний чек» и «Время работы» были вовсе скрыты
  (`nth-of-type(n+5){display:none}`).
- **Стало:** все 6 фильтров видны, ничего не обрезано, перенос в строки,
  шевроны `--accent-dark`, тоггл вида справа, хит-таргеты 44px.
- _Проверка:_ `/restaurants` на 1440 / 980 / 390. Мобильный bottom-sheet
  (≤680px) не тронут. _Коммит:_ `Task 2`.

### Task 3 — Типографика
`next/font`: **Golos Text** → `--font-sans`, **Playfair Display** →
`--font-serif` (вариативные, кириллица, self-host). Все 31 объявления
`font-family` сведены к двум переменным; моноширинный для кода оставлен.
- ⚠️ Заголовки теперь реально рендерятся **Playfair Display** (раньше
  `--font-serif` не был подключён и был фолбэк Georgia). Если нужен старый
  Georgia — откатывается одной строкой в `layout.tsx`.
- _Проверка:_ текст один санс на всех экранах, заголовки — serif, без
  «прыжков» шрифта. _Коммит:_ `Task 3`.

### Task 4 — Плейсхолдер герой-слайдера
Слайды без фото больше не показывают тёмно-коричневый прямоугольник:
тёплая кремовая панель (диагональная текстура + серифная монограмма +
моно-подпись «фото ресторана»). На таких слайдах оверлей светлеет, текст
становится тёмным — заголовок и CTA читаемы. Фото-слайды не изменились.
- _Проверка:_ ресторан без `mainPhotoUrl`/`bannerImage`/галереи на главной.
  _Коммит:_ `Task 4`.

### Task 5 — Схема столов в тёплой палитре
Зелёный/красный/синий → тёплая айдентика (по согласованию):
- свободен → белая карточка + мягкая тень (приподнята над схемой);
- занят/недоступен → плоский приглушённый greige, затемнён (уходит вглубь);
- выбран → терракот (`--accent`) + кольцо (oklch, есть hex-фолбэк);
- депозит → янтарь.
Свободно/занято различаются заливкой+тенью (не оттенком). Легенда обновлена.
Зелёный оставлен только для статусов «подтверждено». Панель зума в редакторе
зала сделана непрозрачной (гость выбирает стол пинчем/скроллом — кнопок нет).
- _Проверка:_ форма брони, выбор стола. _Коммит:_ `Task 5`.

### Task 6 — Выравнивание карточек ресторанов
Карточки в ряду — одинаковой высоты (`align-items:stretch` + `height:100%`),
тело — flex-колонка, кнопка «Забронировать стол» прижата к низу
(`margin-top:auto`). Длинные названия — `text-wrap:balance`.
- _Проверка (layout-probe):_ 3 карточки с разным контентом → одинаковая
  высота (466px) и общая базовая линия CTA. _Коммит:_ `Task 6`.

### Task 7 — Мобиль / Capacitor
- Кнопка «наверх»: `bottom` теперь учитывает `env(safe-area-inset-bottom)`
  — не садится на home-indicator на устройствах с вырезом.
- `html { overflow-x: clip }` — страж от случайного горизонтального скролла
  на телефонах, без превращения `<html>` в y-скролл-контейнер (`clip`, не
  `hidden`), так что липкий хедер и фикс-бары продолжают работать.
- Проверено: safe-area-insets уже стоят в 20+ местах (нижние бары, модалки,
  VK Mini) — добраны два пробела. _Коммит:_ `Task 7`.

### Task 6 (добор) — проверка форм
Поля формы брони (дата / время начала / время окончания / гости) уже
единообразны: общий `min-height:52px` и `border-radius:16px`
(`.reservation-form input, textarea, .pretty-select-trigger`) — выровнены
по высоте и базовой линии, правок не потребовалось.

## Как проверять
Открыть на ширинах **1440 / 980 / 390** (DevTools device toolbar):
- `/restaurants` — фильтр-бар (нет обрезки, все фильтры, тоггл справа),
  ряды карточек (равная высота, кнопки по низу), типографика.
- Главная — герой-слайдер (плейсхолдер у ресторана без фото).
- `/restaurants/<slug>/reserve` — схема столов (тёплые цвета, легенда),
  поля брони одной высоты.

## Доп. раунд — нативка / мобилка / админка

### Native (Capacitor + VK Mini)
`layout.tsx`: добавлен `viewportFit: "cover"` — без него `env(safe-area-inset-*)`
возвращал 0 и весь safe-area-код (20+ мест) был «спящим». Активировав инсеты,
добавил `padding-top: env(safe-area-inset-top)` липким верхним барам
(`.app-header`, `.vk-mini-topbar`), чтобы не лезли под вырез/статус-бар (нижние
бары инсет уже учитывали). На десктопе/в обычном браузере инсеты = 0 → веб-сайт
не затронут. `capacitor.config` маршрутизирует не-в-allowlist навигацию (карты,
оплата) во внешний браузер — это корректно. _Коммит:_ `Task 7 (native)`.

### Каталог — переносы названий
Карточки `.restaurants-grid` не клампили заголовок → длинные названия
(«Кафе-пельменная…») лесенкой. Добавлен ровный `-webkit-line-clamp:2` с
зарезервированной высотой в 2 строки (компактный/мини-варианты — свой кламп).
_Коммит:_ `Task 8 (clamp)`.

### Админка — строки → карточки на мобильном
`*-row` таблицы при ≤1100px схлопывались в столбик безымянных ячеек («каша»).
`.restaurant-admin-row` теперь полноценная карточка (≤720px): блок названия,
бейдж + чип-статистика в одну строку, действия — сеткой 2×2 равных кнопок 44px
под разделителем. Остальные строки (guest/history/application) — действия на всю
ширину, 44px. **Важно:** большинство `overflow-x:auto` в `globals.css` — это
легитимные слайдеры (рейлы, чип-ряды, вкладки, waiter-nav), а не костыли
админ-таблиц, поэтому их не трогал; перенос данных (email/ID/JSON) уже закрыт
секцией TEXT-OVERFLOW. _Коммит:_ `Task 9 (admin cards)`.
